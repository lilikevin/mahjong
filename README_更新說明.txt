麻雀計番完整主程式更新 — v1.4.3-ui

本套件的 app.js 是完整替換檔，不是 patch 片段。以使用者上載的 app_x5f_4_x5f_fixed.js 為基礎，整合先前討論的驗證、計分及 UI 流程。
保留原有外部 CSS、配色、主題及兩段注入式 CSS；兩段 CSS 已核對為完全相同。
本套件不是獨立網站，仍須使用原有 HTML、CSS、engine、worker、manifest、service worker 等檔案。

本次新增
1. 玩家名稱點入即清空，暫存點入前的名稱，顯示「輸入玩家名稱…」。
2. 失焦時：有輸入則修剪前後空白並更新設定草稿；空白、只有空格或刪光則還原點入前名稱。
3. 再次點入以最新草稿名稱為還原值；已儲存玩家名稱不會因清空輸入而立即改變。
4. 按確認時主動讀取四個名稱欄，即使觸控阻止了 blur 仍先完成空白還原再儲存。
5. 名稱 change/blur 不會重繪整頁；背景 render 在名稱輸入期間暫緩，避免換掉正在輸入的欄位。
6. 取消玩家設定不會儲存修改。
7. 每張玩家卡顯示已收付；有未結拉數時另顯示「未收拉」及「未付拉」。兩者分開，不互相抵銷。
8. 牌桌下方保留逐筆「誰欠誰／金額／第幾口」及原有結清按鈕；沒有時顯示「暫無未結算的拉」。
9. 卡片摘要直接由現有 S.ledger 加總，並不改動拉數計法。結清、記錄或撤銷後隨 render 更新。
10. 廣東牌不顯示台牌拉數欄位。

保留先前更新
玩家名稱/emoji/座位/莊家設定；點玩家卡選贏家；自摸/食炮及出銃者選擇；成功記錄返回牌桌。
雙/三響於同一局加入，沿用出銃者，最後一次確認；空白當前手不加入結算。
失敗/取消不清空手牌；返回牌桌可繼續未完成輸入。
廣東牌確認使用 settleHK；自摸不要求共同放炮牌；共同牌只計一次；部分輸入顯示待確認。
最低起糊番數驗證涵蓋 pending-only；普通/廣東牌正式記錄必須通過牌型分析。
廣東牌低於起糊番數仍按原程式詐糊罰分慣例先要求確認。
即時籌碼/罰則保留；玩家 emoji 隨 JSON 備份保存；舊資料無 emoji 時補預設。

安裝
1. 先用網站匯出 JSON 備份，另外保存原 app.js、version.json。
2. 以本套件 app.js 取代原檔；不要改動原有 HTML/CSS/engine/worker 檔名。
3. 同步部署本套件 version.json，或在原版本檔保留其他欄位，只更新 version 為 v1.4.3-ui 與 updated。
4. 若 service worker 固定快取舊 app.js，須按原部署方式更新快取版本／執行原有更新機制。
   未提供原 sw.js，故本套件沒有修改它，不能保證只上傳 app.js 就立即刷新已安裝 PWA。
5. 先在測試副本測試玩家名稱輸入、食炮、自摸、雙響、拉數、結清及撤銷，再部署正式站。

測試
Node.js 語法檢查通過；67 項自動回歸測試通過。
測試使用真實上載的 engine.js、engine2.js、engine4.js、engine_hk.js；載入完整 app.js。
僅在測試執行的記憶體副本注入存取介面，正式檔不包含測試接口。
DOM、localStorage、確認視窗使用模擬；測試無網絡連線。
測試包含 delegated focus/change 事件、未失焦直接確認、空白還原、反向欠款不抵銷、結清與撤銷後更新摘要。
未完成 Safari/iOS 真機、實際鍵盤/IME、手機排版、百搭 worker 及 service-worker 的瀏覽器端全面測試。
未確認的本局手牌草稿仍只保留於本次頁面執行期間，重新載入不保證保留。

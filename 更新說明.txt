麻雀計番 v1.3.1 更新說明

上傳(覆蓋或新增)到網站根目錄:
 app.js、index.html、sw.js、version.json、wild-worker.js(覆蓋)
 mj-core.js(新增)
 t_sup_check.js(新增,只供在電腦檢查用,不影響網頁)
index.html 已加入 <script src="mj-core.js">,必須和 mj-core.js 一起上傳。

文案精簡(6 項):入口頁百搭選項、座位頁提示、改名提示、全新局提示、算番頁三段操作提示、結算頁分享提示。
 連莊規則移到「開局設定」旁的 ❓,點一下才顯示。

P3-1  mj-core.js:共用 decompose()。engine.js / engine2.js / engine_hk.js / engine4.js 各有一份相同的拆牌函數。
      四份各改成一行(見下),改完行為與原本逐字相同(已用兩萬組隨機牌對照驗證)。
      在改好四個引擎之前,舊的拆牌函數仍然有效,mj-core.js 只是多載入一個檔案,不影響使用。
      每個引擎檔:找到 function decompose(cnt,nSets){ ... },整段(到下一個 function 之前)換成:
        function decompose(cnt,nSets){ return MJCORE.decompose(cnt,nSets); }
      位置:engine.js 在 function isLik 之前;engine2.js 在 function isLik2 之前;
            engine_hk.js 在 function isShisan 之前;engine4.js 在 function isLik 之前。

P3-2  t_sup_check.js:在網站資料夾執行  node t_sup_check.js
      檢查四套番表的不複合規則有沒有打錯番種 id、番表有沒有重複 id、有沒有取消自己。

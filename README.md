# 麻雀計番 2.0 整合測試版

## 使用
將本資料夾全部檔案放在獨立的 GitHub Pages 測試 repository 根目錄。
首頁為 index.html；mockup.html 是相同入口。請整組替換，不要沿用上一版 HTML/CSS。
不需要 app.js、sw.js、manifest.json 或 npm build。

## 功能基底
以本次上傳的 app.js（版本欄位 1.5.1）為功能基底，保留其實際存在的計番、拉數、踢半、斬拉、廣東牌付款與包牌、多響驗證、番表、自訂表、備份匯入匯出、草稿及最近5局番數修正重算程式。
新的頁面層使用這些原函數，而非原簡化 mockup 的記帳方法。
新建 wild-worker.js 為原 app.js 所依賴的百搭搜尋提供實作；以候選牌型枚舉，取消會終止 Worker，不會把未完成結果當最高番。

## 介面修正
五段提示在上，下一步為主按鈕；牌面固定修長比例，牌頂有上／碰／明槓／暗槓／食。
明牌選單用實際可用牌組及牌面，不重複使用已標記牌；台牌不詢問門清。
歷史使用已收付＋前後未結算拉數淨變動，不把未收現金當零輸贏。
顏色及番表可在開局前設定。長列表以分頁適配；仍需要手機實機檢查。

## 資料與限制
測試版使用獨立本機儲存 key，不自動讀取或改寫正式1.x帳本，也不讀取最早簡化mockup的資料。
正式1.x備份請先保留原件，再用「匯入備份」導入測試版核對。
最近5局修改沿用原功能：改贏家／出銃者／番數後重播帳目，並非重新打開完整五段手牌修改。
新記錄保存規則快照；舊記錄缺規則快照時需確認才按目前規則重算。
未加入多步Redo、拖曳換位、排名等未獲納入本次範圍的規劃功能。
百搭大量代入、複雜多響／包牌／斬拉與真實付款的組合需額外測試，不應直接替代正式帳本。
未經iPhone瀏覽器全畫面操作或離線測試；本次沒有打包 service worker。

## 已通過的自動測試
- 所有JavaScript語法檢查。
- DOM替身環境啟動（不等於瀏覽器視覺測試）。

- 廣東牌自動對對糊計番；快速記番正式確認入帳。
- 台牌正式確認入帳、撤銷，拉數回復。
- 23 + 莊家連莊5 = 28，只收一次。
- 首次拉數現金0但歷史淨變動為+28 / -28。
- ceil(35×1.5)+120 = 173。
- 明牌候選順子／碰／不足四張不出槓。
- 一張百搭的背景搜尋（完成、代入、結果回傳）。

請先以假牌局測試並保留備份。

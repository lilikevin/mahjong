# 麻雀計番

麻雀計番是一個以繁體中文提供的手機優先網頁程式，可用於港式台牌、港式台牌百搭及廣東牌的計番與牌局結算。程式版本：2.0.14。

## 開始使用

這是靜態網頁程式，沒有 npm 安裝或建置步驟。將 repository 根目錄的檔案完整部署到 GitHub Pages 或其他 HTTPS 靜態網站，然後用瀏覽器開啟 `index.html`。請保留所有檔案並維持原有目錄結構；牌型引擎、樣式、圖示及百搭搜尋 Worker 都是程式的一部分。

在 iPhone 上可用 Safari 開啟網站，依開場提示透過「分享」→「加入主畫面」建立捷徑。瀏覽器分頁與主畫面 App 的本機資料可能分開保存；需要轉移資料時，請先在原處匯出備份，再於新處匯入。

程式會在開啟及重新回到前景時檢查 `version.json`。發布新版本時，請同步更新 `mockup.js` 的 `APP_VERSION`、`version.json` 的版本及日期、`sw.js` 的快取名稱，以及入口 HTML 的 CSS／JavaScript／manifest 資源版本字串；使用者會看到更新提示，可選擇立即刷新或稍後更新。

## 功能

- 支援港式台牌（無百搭）、港式台牌百搭及廣東牌。
- 提供多套預設番表，亦可建立、匯入及匯出自訂番數表。
- 記錄牌局、玩家、莊家與連莊，並提供歷史紀錄及結算。
- 台牌支援拉數及相關結算；廣東牌支援付款設定與包牌等玩法選項。
- 支援備份匯入／匯出、未完成輸入草稿，以及最近牌局的結果修正。
- 百搭牌型搜尋在背景 Worker 執行，可取消尚未完成的搜尋。

## 資料與備份

牌局資料儲存在目前瀏覽器環境的本機儲存空間，不會因部署網站而自動同步到其他裝置或瀏覽器。請定期到「設定」匯出 JSON 備份，並將備份檔保存在安全位置；清除瀏覽器網站資料可能會刪除未匯出的紀錄。

2.0 使用獨立的資料儲存格式，不會自動讀取或改寫舊版 1.x 帳本。匯入舊版資料前，請先保留原始備份，並核對匯入後的玩家、牌局與結算。

## 專案檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網站入口 |
| `mockup.js`、`mockup.css` | 主要介面與互動程式 |
| `mj-core.js`、`engine*.js` | 共用牌型分析及各番表／玩法引擎 |
| `wild-worker.js` | 百搭牌型背景搜尋 |
| `manifest.json`、`icon-*.png` | 主畫面捷徑及圖示資源 |
| `version.json` | 線上版本檢查資訊 |
| `sw.js` | Service Worker 快取設定 |
| `t_sup_check.js` | 檢查番表不複合規則引用的 Node.js 小工具 |

`mockup.html` 是另一個可用的入口頁。部署時建議以 `index.html` 作為首頁，並將本 repository 的檔案一併發布。

## 開發檢查

需要 Node.js。可在專案根目錄執行：

```sh
node t_sup_check.js
```

此工具只檢查各番表的不複合規則及番種 ID，不代表完整的牌型、付款或瀏覽器介面測試。修改 JavaScript 後，可逐檔執行 `node --check <檔案名稱>` 檢查語法。

## 測試提醒

本專案目前是 2.0 測試版。投入正式牌局或真實付款前，請先用假牌局核對番數表、特殊牌型、多響、包牌、斬拉及實際結算；並在目標手機上測試畫面操作。不要把本程式視為帳本備份的替代品。
